# Модули ERP-системы

## Ядро
- Единая база данных
- Справочники (НСИ)
- Права доступа

## Базовые модули
- **Финансы и бухгалтерия**: главная книга, расчёты с дебиторами и кредиторами, казначейство, основные средства, налоговая отчётность
- **Закупки**: заявки, выбор поставщиков, заказы, договоры, приёмка
- **Продажи**: заказы клиентов, ценообразование, отгрузки, счета
- **Склад и запасы**: остатки, перемещения, инвентаризация, партии и серийные номера

## Дополнительные модули
- **Управленческий учёт (контроллинг)**: бюджетирование, учёт затрат, себестоимость, план-факт анализ
- **Производство**: спецификации и маршруты, планирование потребностей (MRP), производственные заказы, загрузка мощностей
- **Персонал (HRM)**: кадровый учёт, табель, расчёт зарплаты, подбор и обучение
- **Логистика и цепочки поставок (SCM)**: планирование спроса, транспорт, доставка
- **CRM**: клиентская база, воронка продаж, маркетинг, сервисные обращения
- **Проекты**: планирование, ресурсы, бюджеты и затраты по проектам
- **Техобслуживание и ремонты (ТОиР/EAM)**: учёт оборудования, графики ремонтов, заявки
- **Управление качеством**: входной контроль, проверки в производстве, несоответствия
- **Аналитика и отчётность (BI)**: дашборды, консолидированные отчёты
